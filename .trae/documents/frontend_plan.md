# 前端重构开发规划 (Frontend Plan)

## 1. 重构目标
当前前端基于原生 Streamlit 搭建，布局死板，缺乏现代对话式 AI 助手（如 Claude）的沉浸感与交互细节。本次规划旨在通过深度定制 CSS 与页面结构，将现有界面改造为类似 Claude 的高级 UI，提供极简、优雅的多模态识图交互体验。

## 2. 设计规范与技术路线
为了在不重写 Python 后端和替换技术栈的前提下实现目标，我们将采用 **Streamlit + 高级自定义 CSS 注入 + 布局重构** 的技术路线。

### 2.1 核心设计理念 (类 Claude 风格)
- **极简框架**：隐藏一切无关的 Streamlit 原生元素（Header、Footer、汉堡菜单、部署水印）。
- **沉浸式聊天区**：主聊天区居中显示，设置最大宽度（例如 `800px` 或 `48rem`），保证阅读舒适度。
- **浅色/深色主题适配**：以浅色背景（如 `#F9FAFB`）为主，搭配高对比度的圆角气泡和文字，或者直接继承用户操作系统的暗黑模式但进行色阶调优。

### 2.2 核心交互重构
1. **欢迎页 (Empty State)**：
   - 聊天记录为空时，不再显示空荡荡的页面。
   - 居中渲染产品名称、简短说明以及 3-4 个**快捷提示词卡片 (Prompt Suggestions)**。
   
2. **多模态附件体验**：
   - 当前的图片上传在侧边栏，显得割裂。
   - 重构逻辑：保留侧边栏上传或改用底部浮动上传控件，当用户上传图片后，在主对话流中渲染一张带有圆角、阴影的**缩略图**，模拟发送图片附件的感觉。

3. **对话气泡与头像**：
   - 移除默认的方形底纹，替换为无边框的流式排版或微弱背景色。
   - 用户头像使用简洁的 User Icon，Agent 头像使用自定义的地质/AI Logo。

4. **输入框悬浮设计**：
   - 使用 CSS 将输入框吸底居中，限制与主聊天区等宽，加入阴影 (Box Shadow) 使其有悬浮层次感。

5. **思考过程展示 (Tool Call Tracing)**：
   - Agent 后台调用视觉、KG 等工具的过程，使用 `st.status` 包裹起来。未完成时显示 Loading 动画，完成后折叠显示“已完成工具调用”，使页面专注呈现最终的 Markdown 地质报告。

## 3. 实施步骤拆解

### Step 1: 建立样式基建
- 在 `frontend/` 目录下创建 `style.css` 文件。
- 编写全局 CSS 覆盖 Streamlit 默认样式（如 `.stApp`, `[data-testid="stHeader"]` 等）。
- 在 `app.py` 中通过 `st.markdown("<style>...</style>")` 动态注入。

### Step 2: 页面骨架与欢迎页开发
- 重新设计 `app.py` 的结构。
- 添加判定逻辑：`if not st.session_state.messages:`，渲染居中的 Claude 风格引导页和示例问题卡片。

### Step 3: 多模态上传机制改造
- 将用户上传的地质图作为“消息状态”的一部分保存（例如增加 `"image"` 字段）。
- 在渲染 `messages` 循环时，如果是带图片的消息，优先渲染漂亮的缩略图。

### Step 4: 聊天流与状态组件优化
- 修改现有 `agent.achat` 调用的 UI 包裹方式。
- 引入 `st.status("思考中...")`，将所有繁杂的内部日志收起，保持输出界面的干净与高信息密度。
