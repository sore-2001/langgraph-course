# 地质识图智能体验收清单 (Checklist)

## 1. 工具层验证
- [ ] `peace_geo_tool` 能够成功输入图片路径并返回规范的 JSON 元数据（包含图例、比例尺、坐标）。
- [ ] `vision_tool` 能够提取主图上的空间要素（断层线、矿点位置），并返回格式化的坐标或关系列表。
- [ ] `spatial_calculator` 能够根据坐标正确计算空间距离和相对位置关系。
- [ ] `kg_tool` 能够正确连接 Neo4j 数据库，并根据实体名返回准确的图谱信息或 GraphRAG 社区摘要。

## 2. 智能体编排验证
- [ ] 智能体完全基于 LlamaIndex 框架构建（未使用 LangGraph）。
- [ ] 智能体能够正确理解地质领域的复杂指令，触发多步推理（ReAct 循环正常工作）。
- [ ] 智能体能够在单次交互中同时调用视觉工具（感知地图）和 KG 工具（检索知识）。
- [ ] 智能体具有上下文记忆能力，能够回答关于同一张地图的连续追问（如：“那断层附近的岩性是什么？”）。

## 3. 前端页面验证 (Frontend Web UI)
- [ ] 用户可以成功上传地质图文件（JPG/PNG 格式）。
- [ ] 提供流畅的对话交互界面，支持智能体的流式文本回复。
- [ ] 能够在界面上可视化展示解析结果（如将检测到的图例或断层高亮叠加在原图上）。
- [ ] UI 布局合理，不卡顿，报错信息友好。

## 4. 整体系统稳定性
- [ ] LLM 能够有效处理工具报错，并尝试自我修正（容错机制生效）。
- [ ] 环境依赖（LlamaIndex, OpenCV, Neo4j, YOLOv10 等）记录完整，可通过 `requirements.txt` 或 `uv.lock` 一键复现。
